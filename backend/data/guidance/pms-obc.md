# Post Matric Scholarship for OBC Students (PMS-OBC) — Guidance

**Ministry:** Ministry of Social Justice & Empowerment
**Scheme ID:** pms-obc | **Category:** Education

## Overview
Post-Matric Scholarship for students belonging to **Other Backward Classes (OBC)** — course fee reimbursement + maintenance allowance for post-matriculation studies, via DBT through NSP/PFMS.

## Eligibility Criteria
1. Student belongs to **OBC** category (valid certificate issued by competent authority).
2. Enrolled in a **recognised post-matriculation course** (Class 11 and above).
3. **Family income from all sources ≤ ₹2,50,000 per year** (current DoSEJ ceiling; earlier ₹1.5L in some state variants).
4. Not in receipt of any other scholarship for the same course.

## Benefit
- Course fee reimbursement + monthly maintenance allowance (day scholar/hosteller slabs) + book grant.
- DBT via PFMS to Aadhaar-linked bank.

## Application Process (NSP)
1. Register at scholarships.gov.in → "New Registration".
2. Fill academic + course details; upload caste and income certificates.
3. Institution, District, State verification online.
4. Release via PFMS; track "Check Your Status".
